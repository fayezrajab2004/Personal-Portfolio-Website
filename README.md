# Personal Portfolio Website

A simple responsive portfolio website built with HTML, CSS, and JavaScript.

## Features

* Responsive design
* Light and dark mode
* Typewriter effect
* Smooth animations
* Skills section
* Education and training
* Real project showcase
* GitHub, LinkedIn, and email contact links

## Technologies

* HTML
* CSS
* JavaScript
